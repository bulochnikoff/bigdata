# Лабораторная работа 1

Вариант 1. Датасет: Amazon Reviews 2023, категория All_Beauty. Ссылка на файл есть в блокноте, сам архив в репозиторий не входит.

Сценарий: рекомендательная система, цель +15% к среднему чеку, задержка выдачи меньше 100 мс.

Блокнот: `лаб1.ipynb`.

Краткий итог. 701 528 отзывов. Несжатый JSONL 311.5 МБ, CSV 185.1 МБ, Parquet 114.4 МБ, Avro 177.8 МБ. Средняя скорость 0.0010 записей/с, пик 0.040 записей/с. Оценки в диапазоне 1–5: 100%. Дубликатов по ключу 7276. Проверка Great Expectations прошла. При чеке 1800 ₽ и марже 25% окупаемость разработки около 2.4 месяца.
