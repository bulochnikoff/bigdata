# Лабораторная работа 6

Вариант 1. Сервис рекомендаций: 10 реплик, из них 8 spot, это 80%.

Блокнот с расчётом стоимости: `лаб6.ipynb`.

Файлы:

| Файл | Зачем |
| --- | --- |
| `лаб6_Dockerfile` | образ сервиса на порту 8080 |
| `лаб6_app.py` | сервис, состояние в checkpoint |
| `лаб6_load.py` | 50 запросов и p95 |
| `лаб6_deployment.yaml` | 2 обычные реплики и 8 spot |
| `лаб6_hpa.yaml` | автомасштабирование |
| `лаб6_pdb.yaml` | PodDisruptionBudget |
| `лаб6_check_manifests.py` | проверка доли spot и checkpoint |
| `лаб6_docker-compose.yml` | локальный запуск образа |

Проверка манифестов из корня репозитория:

```
python лаб6/лаб6_check_manifests.py
```

Локальный сервис из этой папки:

```
docker compose -f лаб6_docker-compose.yml up --build
python лаб6_load.py
```

Кластер Kubernetes этими файлами не поднимается: в блокноте посчитаны стоимость и простой, манифесты лежат рядом для проверки.

Итог расчёта: было 54 000 ₽/мес, стало 23 760 ₽/мес, экономия 56%. Простой на перезапуск 96 мин при бюджете 216 мин для доступности 99.5%.
