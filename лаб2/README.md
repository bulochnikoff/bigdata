# Лабораторная работа 2

Вариант 1. Датасет: Amazon Reviews 2023, категория Software. В репозитории только ссылка, файлы Parquet не хранятся.

Задача: одна и та же агрегация отзывов по товару на Pandas, Dask, Spark, Polars и DuckDB. Срезы около 100 МБ и около 1 ГБ.

Блокнот: `лаб2.ipynb`.
Зависимости: `requirements.txt`.
GPU: каталог `gpu`. Выполнен трек C, без GPU-плагина.

Краткий итог. На срезе около 1 ГБ Pandas 3.21 с, Dask 1.11 с, Spark 0.89 с. Polars быстрее Pandas примерно в 12 раз, DuckDB примерно в 13 раз. Коэффициент вариации отзывов по товару 11. Для этой категории на одной машине достаточно Polars или DuckDB. Spark оставлен для случая, когда данные перестанут помещаться в память одной машины.
