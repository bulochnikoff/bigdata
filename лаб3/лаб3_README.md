# Лабораторная работа 3

Вариант 1. Amazon Reviews 2023, категория All_Beauty.

Сценарий: суточная витрина товара для рекомендательной системы.

Пайплайн ELT: проверка схемы, DLQ, идемпотентный ключ, SQL-модель витрины.

Запуск: открыть `лаб3.ipynb` и выполнить ячейки сверху вниз. Блокнот сам записывает проект dbt во временный каталог и запускает его, если пакет установлен. Отдельная проверка модели из корня репозитория: workflow `.github/workflows/lab3_etl.yml` на Python 3.11 выполняет `python seed_ci.py` и `dbt run` в каталоге `лаб3/лаб3_dbt`.

Краткий итог. Сырых строк 701 528, в чистый слой после отсечения битых попало 694 252. Повторная загрузка оставила те же 694 252 строк, идемпотентность прошла. В DLQ ушло 2 записи, искусственный дрейф схемы перехвачен. В витрине 115 709 товаров. Оценка качества 1.00, `DBT_RAN=True`.
