# Лабораторная работа 4

Вариант 1. Датасет: Amazon Reviews 2023, категория All_Beauty, первые 80 000 отзывов. Файл в репозиторий не входит.

Сценарий: по тексту отзыва предсказать оценку 4–5. Отдельное требование варианта — онлайн-обучение и concept drift.

Оформление: Jupyter Notebook, не Docker.

Блокнот: `лаб4.ipynb`.
Зависимости: `requirements.txt`.

Запуск: открыть блокнот и выполнить ячейки сверху вниз. MLflow пишет эксперименты в локальный `mlflow.db`.

Краткий итог. Лучшая пакетная модель — logreg, F1 0.895, ROC-AUC 0.914. Расхождений офлайн- и онлайн-признаков: 0. p95 одного ответа 1.4 мс при лимите 100 мс. PSI оценок 0.011, детектор сдвига не сработал. F1 застывшего и дообученного SGD на будущем срезе: 0.818.
