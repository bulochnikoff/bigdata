# Лабораторная работа 5

Вариант 1. Сценарий: рекомендательная система на потоке отзывов Amazon Reviews 2023, категория All_Beauty. Уникальное требование — p95 задержки решения по одному событию меньше 65 мс. Это не время ночного пересчёта и не время микробатча.

Окна, опоздавшие события и p95 посчитаны в `лаб5.ipynb`. Зависимости блокнота: `requirements.txt`.

Docker-стенд: Kafka без ZooKeeper и Spark Structured Streaming.

```
docker compose -f лаб5_docker-compose.yml up
```

Команда запускается из этой папки. `лаб5_spark_job.py` читает топик `reviews` и печатает p95 скоринга одного события.

В блокноте: 11 979 событий, в окна поданы 10 182, опоздавших копий 200, повтор не изменил число принятых. p95 скоринга одного события 0.001 мс. Локальный Spark дочитал поток за 5.6 с, в закрытых окнах 11 978 событий. Это время микробатча, его не сравнивают с порогом 65 мс.
